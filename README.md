# 바로담 마켓

더미 데이터로 만든 쇼핑몰 시제품입니다. 실제 판매나 결제는 하지 않습니다.

- 주소: https://barodam.kro.kr
- 상품 500개, 브랜드, 가격, 별점, 후기는 모두 지어낸 데이터입니다.
- 사진은 Openverse의 CC0(퍼블릭 도메인) 이미지입니다. 출처는 [CREDITS.md](CREDITS.md)에 있습니다.

## 기능
- 오늘만 특가(자정까지 카운트다운), 기획전 배너
- 카테고리별 실시간 랭킹
- 검색, 필터(내일 도착, 무료배송, 별점, 할인), 정렬
- 상품 상세: 옵션, 판매처별 가격 비교, 리뷰 키워드
- 찜, 장바구니, 무료배송까지 남은 금액, 가짜 주문 완료

## 수정 방법
`src.html`을 고친 뒤 `python build.py`를 실행하면 `index.html`이 다시 만들어집니다.
